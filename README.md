# Mohamed Ashiq CM (ASKY) — Cinematic Videographer & Editor Portfolio

A luxury, high-performance portfolio website for **Mohamed Ashiq CM**, professional Videographer & Video Editor based in Bengaluru, India.

## ✨ Key Features

- **3D DSLR Cinema Camera Opening**: Pure black intro featuring a centered 3D DSLR camera, smooth optical glass transit, through-the-lens depth, and seamless hero section reveal built with Three.js & GSAP.
- **Continuous Zero-Gap Marquee Carousel**: Hardware-accelerated infinite horizontal sliding carousel in the Services section.
- **Selected Films & Video Modal**: High-definition 4K video teaser playback and cinema modals.
- **Still Photography Gallery**: Dynamic category filters (`Wedding`, `Events`, `Portraits`, `Commercial`) with fullscreen image lightboxes.
- **Django CMS Backend**: Dynamic content management for profile, services, featured films, experiences, and booking inquiries.

## 🚀 Quick Start

### 1. Run with Python / Django
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data
python manage.py runserver
```
Visit: `http://127.0.0.1:8000/`

### 2. Run as Static Frontend
Simply open `index.html` in any modern web browser or live server.
